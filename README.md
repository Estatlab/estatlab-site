# EstatLab

Site do projeto de extensão **EstatLab** — Departamento de Estatística da UEPB.

- `docs/index.html`: página única (publicada pelo GitHub Pages)
- `docs/assets/`: logomarca, sigma (marca d'água) e favicon

## Publicar no GitHub Pages

Em **Settings → Pages**, escolha *Deploy from a branch*, branch `main`, pasta `/docs`.
